# Repository instructions

- Keep content packs append-only and versioned.
- Run `node tests/public-smoke.mjs` after every source or content change.
- Never add runtime profiles, user learning data, local logs, conversation exports, bulk QA screenshots, absolute machine paths, credentials, or private keys. A single maintainer-approved showcase screenshot may be tracked only under `docs/screenshots/` after visual and provenance review.
- Only add art with explicit repository-redistribution rights and update `ASSET_POLICY.md` with provenance and license evidence.
- Keep every assessment paper at 35 questions; increase coverage by adding separate papers instead of lengthening one paper.
