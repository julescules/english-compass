# Third-party notices

The public repository does not bundle the local full edition's third-party anime, visual-novel, background, or character artwork. Source files retain the full edition's image paths and layout rules, while the corresponding raster files remain local and untracked.

`docs/screenshots/english-compass-v111-dashboard.png` is a documentation screenshot of the complete local application. It is included to demonstrate the interface as requested by the project maintainer. Embedded third-party artwork remains subject to its original rights and is not relicensed, distributed as a raw asset, or intended for extraction and reuse.

The application runtime uses only browser and Node.js standard APIs and has no vendored third-party JavaScript dependency.

GitHub Actions used by `.github/workflows/ci.yml` run as hosted development tooling and are not distributed as part of the application.
