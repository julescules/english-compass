# English Compass

**萌系二次元视觉 × Galgame 风一屏学习 × 本地自适应英语训练**

English Compass 是一个无需账号、后端或 API Key 的本地英语学习网站，面向实用英语、海外求职、面试、租房、公共服务、远程协作和跨文化沟通。

## 项目亮点

| 特色 | 体验 |
| --- | --- |
| **精美萌系二次元视觉** | 2D 角色、Galgame 场景、樱花动效与玻璃卡片共同组成主视觉；角色保持正脸清晰、主体完整，不使用 3D 画风。 |
| **六项能力学习闭环** | 单词、语法、翻译、听力、口语、阅读互相连接，练习结果会更新掌握度、薄弱项和次日计划。 |
| **一屏分页，不堆长页面** | 每个模块拆成前后页，桌面和手机都保留固定分页器，题目、角色与按钮不会挤成一条长滚动页。 |
| **大容量实用内容** | 4750 词、360 节语法、680 翻译、680 听力、530 口语场景、280 篇双语阅读。 |
| **短卷综合测试** | 350 道总题库拆成 10 套，每套只做 35 题，并生成六项能力报告。 |
| **本地优先与离线学习** | 进度保存在浏览器本地，可导入导出；PWA 缓存完成后，断网仍可继续大部分练习。 |

当前公开版内容包为 **v1.14.0**：

- 4750 条 A1–C1 词汇与实用词组
- 360 节语法微课
- 680 组中译英练习
- 680 段听力材料
- 530 个口语场景
- 280 篇双语阅读与 840 道理解题
- 10 套综合测试，每套 35 题

## 本地运行

需要 Node.js 20 或更高版本：

```powershell
git clone https://github.com/julescules/english-compass.git
Set-Location -LiteralPath '.\english-compass'
node .\server.mjs
```

然后打开 <http://127.0.0.1:4173>。

学习进度保存在当前浏览器的本地存储中。英文朗读使用系统语音；浏览器在线语音识别不可用时，口语页仍可手动输入并获得表达反馈。

## 主要功能

- 六项能力的每日学习路线、掌握度与间隔复习
- 单词语境复习、听写、词义测试和收藏
- 语法微课、翻译、听力、口语和四页式双语阅读
- 跨模块错题本、学习档案导入导出和 14 天学习足迹
- 一屏分页布局、键盘操作、移动端适配、深色模式和减少动画模式
- PWA 应用外壳离线缓存

## 公开版素材说明

源码保留本机完整工作版现有的二次元图片文件名、摆放位置和裁切规则，没有用重新生成的占位插画替换。由于其中一些素材只允许项目内使用、禁止原素材再分发，另一些缺少逐图公开许可，GitHub 仓库不包含这些栅格原图。维护者的 D 盘公开镜像会自动复制现有素材用于本机预览，但 `.gitignore` 会保证它们不进入提交。

从 GitHub clone 的版本仍可运行全部学习功能；需要视觉素材时，可把你拥有再分发权的独立素材包放入相同的 `assets/...` 路径。详情见 [assets/README.md](assets/README.md) 与 [ASSET_POLICY.md](ASSET_POLICY.md)。

## v1.14 体验与内容修订

- 顶部“学习题库”或 Ctrl+K：统一搜索 7280 项学习内容，按六类练习与 A1–C1 筛选；桌面每页 6 项，手机每页 4 项，可直接进入指定题目，Esc 返回。题库不会中断正在进行的录音，切换未提交翻译前会提示。
- 超长阅读选项在手机上自动进入一屏“阅读专注”：四项完整显示，作答后单独查看双语解析，可返回原文；用全题库最长选项做回归。
- 阅读字号和选项可读性提高；手机采用标题旁角色图，给题目留出空间；新题库采用清晰竖版角色与粉紫卡片。保留樱花雨、悬浮小图和一屏分页。阅读原文页将带书本文字的主图换为现有的无字竖图，原素材保留。
- 编辑修订包 `practice-refinements-v1140.js`：修正 20 篇 C1 阅读的主旨选项中英对齐，并将长句选项改为准确简洁的双语释义，其中 2 篇及 6 道题完整重写；重写 6 条生硬词组的用法和例句，补全 4 条翻译的简短版本与意群。数量保持不变，保留题目 ID 与旧文件。
- 表达匹配会提示与最接近参考句存在的否定或数字差异，并将该次匹配分限制到 59 以下；这仍是本地匹配辅助，不是自由表达的完整语义评分。不再将词面相似直接称为“意思基本到位”。
- 公开版验证：`node tests/public-smoke.mjs`。本机完整素材版另已完成五视口交互、完整综合测试、最长阅读题及离线重载验收。
